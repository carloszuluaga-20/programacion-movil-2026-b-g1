# 1. Idea, problema, público objetivo y MVP

## Idea del proyecto

El proyecto consiste en desarrollar una aplicación móvil llamada **App de Horario para Estudiantes**, enfocada en ayudar a los estudiantes a organizar su información académica de forma sencilla.

La aplicación permitirá consultar el horario de clases, visualizar información de las materias y registrar las notas obtenidas durante el semestre.

## Problema

Muchos estudiantes manejan su información académica en diferentes lugares, como cuadernos, capturas de pantalla, chats o aplicaciones separadas.

Esto puede generar problemas como:

- Olvidar horarios de clase.
- Confundir las materias.
- No llevar un control claro de las notas.
- Tener la información académica desorganizada.

La aplicación busca reunir esta información en un solo lugar y facilitar su consulta desde el celular.

## Público objetivo

La aplicación está dirigida principalmente a:

- Estudiantes universitarios.
- Estudiantes que manejan varias materias durante el semestre.
- Personas que desean organizar de manera sencilla sus horarios y notas académicas.

## MVP - Producto Mínimo Viable

Para la primera versión de la aplicación se definieron tres funciones principales.

### 1. Consultar horario de clases

El estudiante podrá visualizar las materias que tiene programadas y su respectivo horario.

### 2. Consultar materias

El estudiante podrá visualizar información básica de cada materia registrada.

### 3. Registrar y consultar notas

El estudiante podrá registrar las notas obtenidas en cada materia y posteriormente consultarlas.

## Objetivo del MVP

El objetivo del MVP es contar con una primera versión funcional que permita resolver las necesidades principales del estudiante sin agregar funcionalidades innecesarias.

Estas tres funciones permiten validar la idea inicial del proyecto y sirven como base para futuras mejoras.
